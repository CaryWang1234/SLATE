1 SLATE 是什么？What is SLATE?

SLATE（砚）是一款本地优先的 AI 协作调度台。它把主流大模型、30 个内置工具、团队辩论、DAG 工作流、白板式逻辑链整合在一个轻量界面里——零 npm、零构建、开箱即用。

核心理念：让灵感直达行动，中间不隔工具摩擦。

SLATE is a local-first AI collaboration studio. It integrates mainstream LLMs, 30 built-in tools, team debates, DAG workflows, and whiteboard logic chains — all in a lightweight interface. Zero npm, zero build, ready to use.

Core philosophy: Let ideas go straight to action, without tool friction in between.
2 安装与启动Installation & Quick Start

方式一：安装包（推荐）

前往 GitHub Releases 下载 SLATE-Setup-x.x.x.exe，双击安装即可。

方式二：源码运行

git clone https://github.com/CaryWang1234/SLATE.git
cd SLATE
pip install -r requirements.txt
python desktop.py

源码启动后访问 http://127.0.0.1:8000。

首次配置：

  1. 点击左下角 设置 ⚙
  2. 在「模型」栏添加 API Key（支持 OpenAI / Claude / Gemini / DeepSeek / 自定义端点）
  3. 选择默认模型，即可开始对话

Option A: Installer (Recommended)

Download SLATE-Setup-x.x.x.exe from GitHub Releases and run the installer.

Option B: From Source

git clone https://github.com/CaryWang1234/SLATE.git
cd SLATE
pip install -r requirements.txt
python desktop.py

After starting from source, visit http://127.0.0.1:8000.

First-Time Setup:

  1. Click Settings ⚙ (bottom-left)
  2. Add your API Key (OpenAI / Claude / Gemini / DeepSeek / custom endpoints)
  3. Select a default model and start chatting

3 多模型对话Multi-Model Chat

SLATE 支持同时接入多个模型，在对话界面顶部下拉框随时切换。

  • 点击模型下拉框 → 添加/切换模型
  • 不同对话可使用不同模型
  • 支持本地模型（Ollama / LM Studio 的 OpenAI 兼容端点）
  • 每条回复显示模型名称与 Token 用量
快捷键：Enter 发送 · Shift+Enter 换行 · Ctrl+N 新建对话

SLATE supports multiple models simultaneously — switch anytime from the top dropdown.

  • Click model dropdown → Add/switch models
  • Different conversations can use different models
  • Supports local models (Ollama / LM Studio via OpenAI-compatible endpoints)
  • Each reply shows model name and token usage
Shortcuts: Enter to send · Shift+Enter for newline · Ctrl+N for new conversation
4 Agent Autopilot + 目标模式自主执行Agent Autopilot + Target Mode

Agent Autopilot 是默认的”少打继续”执行层。只要你要求 SLATE 查看项目、修改文件、运行命令、排查 bug、提交代码或生成文件，它会自动进入多轮 Agent Loop，不需要反复发送”继续”。

默认轮数：普通环境任务最多 18 轮；全面排查、项目级、多文件任务最多 28 轮。系统会把工具结果隐藏回灌给模型，让它继续观察 → 执行 → 验证 → 汇报。

如果模型只说”我将检查 / 接下来修改 / 是否继续”，系统会自动催它直接调工具；如果没有任何工具记录却口头说完成，系统会要求它先验证或真正动手。

目标模式 是更强的显式闭环模式。需要 50 轮长任务、明确 TODOLIST 和六阶段约束时，点击顶栏 按钮，或在消息中提及「用目标模式执行」。

六阶段流程：

  1. 目标理解 → 解析你的需求
  2. 计划制定 → 拆解为可执行步骤
  3. 工具执行 → 自主调用文件/终端/搜索等工具
  4. 验证检查 → 确认每步结果
  5. 汇报总结 → 输出执行报告
  6. 追溯归档 → 记录到 TODOLIST
特性：最多 50 轮自主调用 · 中途可暂停不丢进度 · 自动建立 TODOLIST · 异常自动恢复

Agent Autopilot is the default "do not make me type continue" execution layer. When you ask SLATE to inspect a project, edit files, run commands, debug, commit, or generate files, it automatically enters a multi-round Agent Loop.

Default budgets: ordinary environment tasks can auto-advance up to 18 rounds; broad project-wide or multi-file tasks can auto-advance up to 28 rounds. Tool results are fed back invisibly so the model can continue Observe → Act → Verify → Report.

If the model only says it will inspect/edit/continue, SLATE nudges it to call tools. If it claims completion without any tool evidence, SLATE asks it to verify or actually act first.

Target Mode is the stronger explicit loop. Use the ⚡ button, or mention "use Target Mode", when you want 50 rounds, TODOLIST enforcement, and six-phase constraints.

Six-Phase Flow:

  1. Goal Understanding → Parse requirements
  2. Plan Creation → Break into steps
  3. Tool Execution → Autonomously call tools
  4. Verification → Confirm each result
  5. Report → Output summary
  6. Trace → Log to TODOLIST
Features: Up to 50 rounds · Pause anytime · Auto TODOLIST · Auto-recovery

5 磨墨模式Grind Mode

把粗糙想法研磨成结构化任务书（墨稿）的交互式引导。

启动：输入 /grind 你的想法 或点击 🖌 按钮。输入抽象任务（如"制作一个网站"）时自动建议切换。

阶段说明
接墨AI 复述想法，列出 3-5 个缺口，只问第一个
磨墨逐轮追问，一次一问，选择题优先（最多 10 轮）
收墨输出结构化 JSON 墨稿，含目标/交付物/验收标准

收墨触发：输入「收墨」「够了」「就这样」或达到轮数上限

墨稿三键：送入目标模式执行 / 投到白板推演 / 存为模板复用

Interactive refinement: turn rough ideas into structured task briefs.

Launch: Type /grind your idea or click 🖌. Auto-suggests when detecting abstract tasks.

PhaseDescription
ReceiveAI restates idea, lists 3-5 gaps, asks only the first
GrindRound-by-round, one question at a time, A/B choices preferred (up to 10 rounds)
CollectOutputs structured JSON brief with goals/deliverables/acceptance

Trigger Collect: Type "收墨" / "够了" / "就这样" or reach round limit

Three Actions: Send to Target Mode / Push to Whiteboard / Save as Template

6 团队模式Team Mode

多个 AI 角色围绕你的问题进行多轮辩论，最终输出共识结论。

  1. 点击顶栏「团队」标签
  2. 选择团队成员（9 种预设组合或自定义）
  3. 输入问题 → 各成员按角色依次发表观点（3 轮辩论）
  4. 输出共识总结

自定义团队：设置 → 团队管理 → 添加/编辑成员，每个成员可指定模型、角色、人设。

Multiple AI roles debate your question across rounds, producing a consensus conclusion.

  1. Click "Team" tab
  2. Select members (9 presets or custom)
  3. Enter question → Members speak in role order (3 rounds)
  4. Consensus summary output

Custom Teams: Settings → Team Management → Add/Edit members with model, role, persona.

7 白板逻辑链Whiteboard Logic Chain

可视化的卡片 + 连线系统，用于梳理思路、推演方案。

  • 点击「黑板」标签进入
  • AI 可自动创建卡片（分析结果、方案对比等）
  • 手动拖拽卡片、建立连线
  • 顶栏可切换 Git / 流程 / 看板 / 纲要等显示模式；主黑板就是默认自由画布
  • Git 树识别 HEAD、branch、remote branch、commit、tag、remote、worktree、stash、暂存 / 修改 / 未跟踪计数、未推送提交；节点与视野均可拖动
  • 4 种 AI 白板工具：card_create · card_edit · arrow_create · board_summarize

Visual cards + connections system for reasoning and planning.

  • Click "Whiteboard" tab to enter
  • AI auto-creates cards (analysis, comparisons)
  • Drag cards, create connections manually
  • Switch display modes from the header: Git, Flow, Kanban, and Outline. The main whiteboard is the default freeform canvas.
  • Git Tree recognizes HEAD, branches, remote branches, commits, tags, remotes, worktrees, stash, staged/changed/untracked counts, and unpushed commits. Nodes and viewport are draggable.
  • 4 AI tools: card_create · card_edit · arrow_create · board_summarize

11 知识库与灵光Knowledge Base & Sparks

知识库：长期存储项目知识，对话时自动注入相关上下文。设置 → 记忆与画 → 知识库标签，支持 Markdown。

灵光（Spark）：对话结束时自动捕获有价值的技术洞察，确认后存入知识库，无需手动操作。

Knowledge Base: Long-term project knowledge storage, auto-injected into conversations. Settings → Memory → Knowledge tab. Markdown supported.

Sparks: Auto-captures valuable technical insights when conversations end. Confirms and stores automatically.

12 Code ReviewCode Review

对 Git 仓库变更进行 AI 四维度结构化审查。

  1. 设置 → Code Review → 选择仓库路径
  2. AI 读取 git diff → 分析代码质量/安全性/性能/可维护性
  3. 输出行级评论 + 汇总报告

AI-powered four-dimensional structured review of Git changes.

  1. Settings → Code Review → Select repository path
  2. AI reads git diff → Analyzes quality/security/performance/maintainability
  3. Outputs line-level comments + summary report

13 语音输入Voice Input

点击输入框旁的 🎤 按钮，说出想法，实时转写到输入框。支持中英文自动检测。需浏览器支持 Web Speech API（Chrome / Edge 已支持）。

Click 🎤 button next to the input box, speak your idea, real-time transcription appears. Auto-detects Chinese and English. Requires Web Speech API (Chrome / Edge supported).

14 截图转代码Screenshot to Code

将截图还原为 HTML/CSS 代码。在对话中描述「把截图转成代码」或 @screenshot_to_code 指定图片路径。

支持格式：PNG / JPG / JPEG / GIF / WebP / BMP / SVG（≤10MB）

Convert screenshots to HTML/CSS code. Describe "convert screenshot to code" or use @screenshot_to_code with image path.

Formats: PNG / JPG / JPEG / GIF / WebP / BMP / SVG (≤10MB)

15 定时任务Scheduled Tasks

点击顶栏 ⏰ 按钮，新建任务 → 设置名称、触发条件（定时/事件）、执行内容。支持 Cron 表达式。

  • 定时触发：每隔 N 分钟/小时/天
  • 事件触发：文件变更、对话结束等

Click ⏰ button, create task → Set name, trigger (schedule/event), execution content. Supports Cron expressions.

  • Schedule: Every N minutes/hours/days
  • Event: File changes, conversation end, etc.
