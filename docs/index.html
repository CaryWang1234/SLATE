Features

功能全景

既能直接驱动内置工具完成任务，也能生成高质量 Prompt 交给外部 Coding Agent（Claude Code、Codex、Cursor 等）执行。

🗣️
多模型统一接入
GPT / Claude / Gemini、DeepSeek / Kimi / Qwen / GLM 等国内外主流模型，支持自定义 OpenAI 兼容端点与本地模型（Ollama / LM Studio）。
⚡
Harness 自主执行
模型自主规划、多轮调用工具直至任务完成，金色进度条实时可见，随时可停止。
🛠️
13 个内置 MCP 工具
文件读写编辑、终端沙箱、仓库统计、正则测试、文本摘要等，@提及即用。
🧩
自定义 Skill 系统
SKILL.md 即插即用，上传或导入即可扩展新能力，聊天中 @ 提及自动注入上下文。
👥
AI 团队多轮辩论
多角色提案 / 反驳 / 决策，轻量模型讨论、重型模型拍板，自动摘要节约 token。
⏰
定时对话任务
单次 / 每日定点 / 固定间隔调度，到点自动执行预设提示词，结果归档独立会话。
🧠
白板式逻辑链
灵感卡片化，拖拽布局、箭头连线标识依赖与数据流，Mermaid 渲染图表。
💾
长期记忆 & 知识库
自动沉淀对话要点，跨会话召回；本地知识片段检索注入。
🏭
提示词工厂
宪法摘要 → 上下文片段 → 任务描述 → 约束 → 交付要求，一键整合为可交付 Prompt。
Highlights

为长任务而生的工程细节

⚡ Harness：让模型自己干完

开启 Harness 后，模型按"拆解 → 执行 → 验证 → 报告"自主推进，无需人工逐步喂指令。

  • 工具调用轮数提升至 10–50 轮
  • 金色进度条实时显示执行轮次
  • 输出截断自动续写，最多 3 轮拼回原文
# 开启 ⚡ 后发送任务
你 ▸ 整理本项目全部 API 并生成文档
Harness 自主执行 · 第 3/20 轮
砚 ▸ ✓ 完结报告：已生成 docs/api.md …

🛡️ 永不卡死的四层防线

参考主流 Agent 的流式健壮性方案，从连接层到界面层层兜底。

  • 流式 idle 看门狗：90 秒无数据主动断开
  • 零内容自动退避重试
  • 请求 / MCP 工具 180 秒超时
  • UI 兜底看门狗强制恢复界面
// frontend/js/services/api.js
STREAM_IDLE_TIMEOUT_MS = 90000
STREAM_MAX_RETRIES     = 2
REQUEST_TIMEOUT_MS     = 180000
// 慢 ≠ 死：持续有数据永不干扰

Tech Stack

原生技术，零构建

前端即文件，改完即生效；没有 npm，没有打包器，没有框架税。

层级选型
前端原生 HTML + CSS + JavaScript（ES Modules，零构建）
后端Python 3.13+ · FastAPI · Uvicorn · httpx
存储SQLite（对话历史）· JSON（状态 / 定时任务 / 宪法）
渲染Highlight.js · Mermaid.js（CDN）
桌面webview2 壳 + PyInstaller 打包 + Inno Setup 安装器

纯黑白灰基底

无蓝紫渐变、无圆角大礼包、无阴影毛玻璃。

本地优先

数据全部存本地，API Key 仅用于 LLM 调用。

Token 节约

智能压缩、分级调用、静默处理。

永不卡死

四层超时防线，流式与工具调用全程兜底。

Quick Start

三步开始研磨

01

获取 SLATE

下载 Windows 安装包开箱即用，或克隆源码：

git clone https://github.com/CaryWang1234/SLATE.git
02

启动

源码运行需要 Python 3.13+：

pip install -r requirements.txt
start.bat  # 或 ./start.sh
03

配置模型

在设置中填入所需模型的 API Key，访问本地服务：

http://127.0.0.1:8000
