Features

Feature Landscape

SLATE offers two paths: let it take action — driving built-in tools to complete tasks directly; or let it strategize — generating high-quality prompts for external Coding Agents (Claude Code, Codex, Cursor, etc.) to execute. Both paths work.

🗣️
Unified Multi-Model Access
GPT / Claude / Gemini, DeepSeek / Kimi / Qwen / GLM and more — plus custom OpenAI-compatible endpoints and local models (Ollama / LM Studio). Switch anytime in one interface, use different "brains" for different tasks.
One remote control for all AIs — switch to whichever is cheapest or best suited.
⚡
Harness Autonomous Execution
Model autonomously plans, calls tools for up to 50 rounds until the task is done, following a six-phase loop: Goal → Plan → Execute → Verify → Report → Trace. Large tasks auto-generate a TODOLIST for batch tracking. Stop only interrupts the current round without quitting.
Like delegating to a reliable intern — state the goal, they finish, check, and report. You can pause anytime without losing progress.
🖌️
Grind Mode
Type /grind with a rough idea, AI follows a three-phase questioning process (Receive → Grind → Collect, up to 7 rounds) to refine it into a structured task brief with goals, deliverables, and acceptance criteria. The ink panel tracks resolved vs. unknown items in real-time.
Put "I have a vague idea" into the inkstone — what comes out is a clear task specification.
🛠️
25 Built-in MCP Tools
File read/write/edit/append, terminal sandbox, PPT / Word generation, SVG charts & QR codes, repo stats, regex testing, text summarization, web search & page scraping, code review, browser & desktop automation — @mention in chat to use, model autonomously calls and displays results. Charts and QR codes render inline.
MCP is "AI's standard socket" — plug in tools and it doesn't just talk, it acts.
🛡️
High-Risk Command Approval
Terminal commands go through dual-layer interception with hardcoded rules: 23 categories of high-risk operations require your confirmation, catastrophic commands are unconditionally blocked, and the approval popup shows AI's explanation of the command's purpose.
Before AI hits "delete," it must first show you what it's deleting and why.
🧩
Custom Skill System
SKILL.md is plug-and-play — upload or import to extend capabilities. @mention in chat auto-injects context, no need to re-explain background and rules.
A Skill is a "job description" for AI — one Markdown file teaches it a new capability.
🎓
Expert Packs
persona.md + rules.md + knowledge/ + skills/ — five pieces packed into one zip per expert. Inject via chat dropdown, team member cards, or @mention. Import and use instantly, share anytime.
It's like "onboarding" for AI — give it the job description and reference materials, and it works in character.
👥
AI Team Multi-Round Debate
Multi-role propose / support / oppose / rebut / decide. Light models handle discussion, heavy models make final calls. Auto-generated summaries save tokens — collective wisdom without the scary bill.
Let several AIs argue it out first, then give you a consensus. Important decisions shouldn't rely on gut feelings.
🔀
Team Workflow DAG
Requirements → Decompose → Code → Review → Summarize — the team follows a predefined DAG pipeline. Upstream output flows to downstream, each node's status and I/O visible in real-time, finished artifacts auto-archived to the knowledge base.
Build an assembly line for the AI team: each station does its job, handoffs flow all the way through, finished products auto-stored.
⏰
Scheduled Chat Tasks
One-time / daily at time / fixed interval — three scheduling modes. Auto-execute preset prompts on schedule, results archived to dedicated sessions. Daily reports, periodic inspections, routine organization — let it handle it.
Set an alarm for AI — it works on its own when the time comes, then files results in a dedicated folder.
🧠
Whiteboard Logic Chain
Turn ideas into cards, drag to layout, connect with arrows to mark dependencies and data flow. Mermaid renders flowcharts and mindmaps — untangle the knots in your head by spreading them out on the desk.
A whiteboard covered in sticky notes — turning "I have an idea" into "here's the implementation path."
💾
Long-Term Memory & Knowledge Base
Auto-distill chat highlights, recall across sessions — AI learns your preferences over time. Local knowledge snippets retrieved and injected on demand, turning your materials into its reference library.
AI no longer has "goldfish memory" — what you discussed last time doesn't need re-explaining.
🔍
Code Review
Reads git diff (unstaged / staged / commit range), AI reviews code across four dimensions — quality, security, performance, maintainability — and outputs a structured report with inline line-level comments. Three views: full report, comment list sorted by severity, and dimension cards.
Like having a senior engineer review every commit — catches issues before they become bugs.
🔔
Task Completion Notifications
When long tasks finish — Harness autonomous execution, team debates, or workflow pipelines — SLATE plays a chime sound and sends a system notification. Both can be toggled independently in Settings. Step away without fear of missing results.
Like a timer for AI tasks — you get notified the moment the work is done.
🔒
Full Sandbox Security
Seven-layer defense: path traversal prevention (sensitive system dirs blacklisted), credential file access blocked, output truncation (50K chars), file size limits (5MB), request body cap (20MB), upload filename sanitization, ReDoS timeout protection. All transparent to users — zero friction, maximum safety.
Like a security guard that never sleeps — blocks threats silently, never slows you down.
📖
Better Project Understanding
Three scan levels — brief / balanced / detailed — priority-read key files, auto-generate a project guide & encyclopedia and a rulebook, persisted for instant access. AI reads the project first, then gets to work.
Give AI "orientation training" first: what it is, how it's structured, what rules it follows — all clearly documented.
🗂️
Chat & Data Management
Full-text search jumps to sessions, export as Markdown / rename / batch manage, messages editable/deletable. One-click JSON backup of all data, import to restore. Storage usage itemized, database compression and cache cleanup in one click.
Chat history is searchable, exportable, editable. Pack up everything in one click. Disk usage is crystal clear.
🏭
Prompt Factory
Constitution summary → context snippets → task description → constraints → delivery requirements — assembled into a deliverable prompt in one click. Structured, complete, ready to feed any Coding Agent.
Turn "help me build something" into a well-organized requirements document, then hand it to AI. Less rework.
📡

Opens port 8001 on launch for LAN access. Phone / tablet browser gets the full interface. Settings page and top-bar 📡 button prominently display the access URL and QR code — scan to connect.
Turn SLATE into a "home radio station" — scan a QR code from your phone, command AI from the couch.
🌍
Multilingual UI
Choose Simplified Chinese or English during installation. The entire interface, toasts, and dialogs are fully localized — no in-app language switching needed, it just works in your language from day one.
Pick your language once at install. SLATE speaks it fluently ever after.
Highlights

Engineering Details Built for Long Tasks

Most AI tools "chat well" but "can't finish" — long tasks break, forget, or freeze. SLATE's engineering focus is exactly here: making long tasks completable, progress visible, and interruptions recoverable.

⚡ Harness: Let the Model Finish It

With Harness enabled, the model follows a six-phase loop: Goal → Plan → Execute → Verify → Report → Trace. Large tasks auto-generate a TODOLIST for batch tracking — no sign-off until all items are resolved. No need to feed instructions step by step.

Harness is "hands-free mode." Assign the task, go grab a coffee, come back to review results. Want to pause? One-click brake.
  • 50 tool-call rounds by default, long tasks stay connected, model sees current round and remaining budget each turn
  • Exits only on: manual stop / rounds exhausted / TODOLIST done — stop doesn't quit Harness
  • Model failures, zero output, repeated calls all auto-intercepted and recovered, loop never breaks
  • Gold progress bar shows round count and checklist progress in real-time, auto-reminds until checklist done
  • Four-layer truncation defense: 6-round anchor continuation + truncation guard + file_append segmented write, long files always complete
# Enable ⚡ then send a task
You ▸ Catalog all APIs in this project and generate documentation
Harness autonomous · Round 3/50 · Checklist 2/5
SLATE ▸ ✓ Final report: generated docs/api.md …

🛡️ Four-Layer Anti-Freeze Defense

Long tasks最怕 spinning forever. SLATE deploys four layers of defense, from the connection layer all the way to the UI — if any layer fails, the next one catches it.

Like a circuit breaker — trips to protect, one-click reset. You'll never stare at a frozen screen.
  • Streaming idle watchdog: disconnects after 90 seconds of no data
  • Zero-content auto-backoff and retry
  • Request / MCP tool 180-second timeout
  • UI fallback watchdog forces interface recovery
// frontend/js/services/api.js
STREAM_IDLE_TIMEOUT_MS = 90000
STREAM_MAX_RETRIES     = 2
REQUEST_TIMEOUT_MS     = 180000
// Slow ≠ dead: continuous data = no interference

Tech Stack

Native Tech, Zero Build

Frontend is files — edit and it takes effect. No npm, no bundler, no framework tax. For developers, it's source code you can read line by line. For users, it means fewer dependencies, faster startup, fewer failure points.

A quick note on a common term: Tokens are AI's "word count unit" for billing and memory — the longer the context, the more it costs and the more it forgets. SLATE's smart context compression condenses old conversations into summaries, like "archiving notes" for your chat history — saves tokens without losing key points.

LayerChoiceWhat It Means
FrontendVanilla HTML + CSS + JavaScript (ES Modules, zero build)Open any file to edit, refresh to see changes
BackendPython 3.13+ · FastAPI · Uvicorn · httpxLightweight service, one command to start
StorageSQLite (chat history) · JSON (state / schedules / constitution)No external database, all data on your disk

Pure Black-White-Gray Base

No blue-purple gradients, no excessive rounding, no shadow/frosted glass. Gold is only an accent — like a stroke of gold lacquer on an inkstone, quiet yet weighty.

Local-First

All data stored locally. API Keys used only for LLM calls. Your chats, memories, and files never pass through any third-party servers.

Token Economy

Smart compression, tiered calls, silent processing. Every token spent wisely — spend less, get more done.

Never Frozen

Four-layer timeout defense, streaming and tool calls covered end-to-end. Slow is waitable. Infinite spinning is not.

Quick Start

Three Steps to Start Grinding

Non-coders only need step one: download the installer, double-click, and use it like any regular software. Those who want to read source code or build on top of it should read all three.

01

Get SLATE

Download the Windows installer from Releases for instant use, or clone the source to explore:

git clone https://github.com/CaryWang1234/SLATE.git
02

Launch

Running from source requires Python 3.13+. Two commands to start the local service:

pip install -r requirements.txt
start.bat  # or ./start.sh
03

Configure Models

Enter API Keys for your desired models in Settings (apply on each model's website, pay-per-use, very low cost for daily use), then visit:

http://127.0.0.1:8000

After installation you get: a dual-themed three-column workspace, all built-in tools, a scheduled task dispatcher, and usage data all stored locally. Clean uninstall, no residue.
