Features

功能全景

SLATE 有两条路可走：要么让它自己动手——直接驱动内置工具完成任务；要么让它出谋划策——生成高质量 Prompt 交给外部 Coding Agent（Claude Code、Codex、Cursor 等）执行。两条路，都走得通。

🗣️
多模型统一接入
GPT / Claude / Gemini、DeepSeek / Kimi / Qwen / GLM 等国内外主流模型，支持自定义 OpenAI 兼容端点与本地模型（Ollama / LM Studio）。同一个界面里随时切换，不同任务用不同的"脑"。
一个遥控器管所有 AI，哪家便宜、哪家擅长就换哪家。
⚡
Harness 自主执行
模型自主规划、最多 50 轮调用工具直至任务完成，按“目标→计划→执行→验证→汇报→追溯”六阶段推进，大任务自动建立 TODOLIST 统筹批量销账；停止仅中断当轮不退出，仅手动停止 / 轮数用完 / 清单了结才结束，模型侧异常自动恢复推进。
像派活给靠谱实习生——说清目标，他自己干完、自己检查、交报告；中途喊一嗓子也不会撂挑子不干。
🖌️
磨墨模式
输入 /grind 加一句粗糙想法，AI 按"接墨→磨墨→收墨"三段式追问（上限 7 轮），把想法研磨成含目标、交付物、验收标准的结构化任务书；墨迹面板实时标记已定与未知，成稿一键送入 Harness 执行、投到白板推演或存为模板。
把"我有个模糊的想法"放进砚台里磨一磨，出来的就是一份清清楚楚的任务书。
🛠️
21 个内置 MCP 工具
文件读写编辑追加、终端沙箱、PPT / Word 文档生成、SVG 图表与二维码、仓库统计、正则测试、文本摘要、联网搜索与网页抓取等，聊天时 @提及即用，模型按需自主调用并展示执行结果，图表/二维码等图片产出直接内联预览。
MCP 就是"AI 的标准插座"——给 AI 接上工具，它不但会说，还会动手做。
🛡️
高危命令审批
终端命令经写死规则前后端双层拦截：rm / format 等 23 类高危操作必须经你确认，灾难级命令无条件禁止，批准弹窗由 AI 解释命令目的。
AI 想按"删除"键之前，得先让你看清它要删什么、为什么删。
🧩
自定义 Skill 系统
SKILL.md 即插即用，上传或导入即可扩展新能力，聊天中 @ 提及自动注入上下文，不用重复交代背景与规矩。
Skill 是写给 AI 的"岗位说明书"，一个 Markdown 文件就能教会它一项新本事。
🎓
专家包
persona.md + rules.md + knowledge/ + skills/ 五件套，一个 zip 打包一位专属专家。对话下拉、团队成员卡、@提及三路注入，导入即用，随时分享。
相当于给 AI 办"入职"：岗位说明书和参考资料一并交给它，它就按这个人设专业干活。
👥
AI 团队多轮辩论
多角色提案 / 支持 / 反驳 / 决策，轻量模型负责讨论、重型模型负责拍板，自动摘要节约 token——集思广益，但账单不吓人。
让几个 AI 先开会吵一架，再给你一个共识结论，重要决定不靠拍脑袋。
🔀
团队工作流 DAG
需求 → 拆解 → 编码 → 审查 → 总结，团队按预定义的 DAG 流水线自动推进：上游产出逐层传给下游，每个节点的状态、输入、输出实时可见，跑完产物自动归档进知识库。
给 AI 团队搭一条流水线：每个工位只管干自己的活，一路交接到底，成品自动入库。
⏰
定时对话任务
单次 / 每日定点 / 固定间隔三种调度，到点自动执行预设提示词，结果归档进独立会话。日报提醒、定时巡检、周期性整理，交给它就行。
给 AI 上个闹钟——到点自己干活，干完把结果放进专门的文件夹。
🧠
白板式逻辑链
灵感卡片化，拖拽布局、箭头连线标识依赖与数据流，Mermaid 渲染流程图与思维导图——脑子里的线团，摊开在桌面上理清楚。
一块贴满便利贴的白板，把"我有个想法"变成"这是实现路径"。
💾
长期记忆 & 知识库
自动沉淀对话要点，跨会话召回，AI 越用越懂你；本地知识片段按需检索注入，你的资料成为它的参考书。
AI 不再"金鱼记忆"——上次说过的事，这次不用从头交代。
📖
Better Project Understanding
简略 / 平衡 / 详细三档力度扫描整个项目，按优先级精读关键文件，自动生成导览·百科与规则手册两份文档并持久化——AI 先读懂项目，再动手干活。
先让 AI 把项目"岗前培训"一遍：是什么、怎么分、守什么规矩，写得明明白白。
🗂️
对话与数据管理
历史全文搜索直达会话，会话导出 Markdown / 改名 / 批量管理，消息可编辑删除；全部数据一键备份为 JSON、导入即恢复；存储用量分项可见，数据库压缩与缓存清理一键完成。
聊天记录能搜、能导、能改；家当一键打包带走，硬盘占用说得清清楚楚。
🏭
提示词工厂
宪法摘要 → 上下文片段 → 任务描述 → 约束 → 交付要求，按固定工序一键整合为可交付 Prompt，结构完整、可直接投喂任何 Coding Agent。
把"帮我做个东西"加工成一份条理清楚的甲方需求书，再交给 AI 去执行，少返工。
📡
局域网遥控
应用启动即在 8001 端口开放局域网访问，手机 / 平板浏览器打开即是完整同一界面；设置页与顶栏 📡 按钮醒目展示访问网址与二维码，扫码即连。
把 SLATE 变成家里的“公共电台”——手机扫个码，沙发上也能指挥 AI 干活。
Highlights

为长任务而生的工程细节

大多数 AI 工具"聊得来"，却"干不完"——任务一长就断、就忘、就卡。SLATE 的工程重心恰恰在这里：让长任务跑得完、进度看得见、中途断不了。

⚡ Harness：让模型自己干完

开启 Harness 后，模型按"目标 → 计划 → 执行 → 验证 → 汇报 → 追溯"六阶段自主推进，大任务先建 TODOLIST 统筹批量销账，未完成不许收尾——无需人工逐步喂指令。

Harness 就是"放手模式"。你布置任务后可以起身倒杯咖啡，回来验收结果；中途想喊停，一键刹车。
  • 工具调用轮数默认 50 轮，长任务不断线，模型每轮可见当前轮次与剩余预算
  • 仅三种情况退出：手动停止 / 轮数用完 / TODOLIST 全部了结，停止不退出 Harness
  • 模型侧失败、零输出、重复调用均自动拦截并恢复推进，循环不中断
  • 金色进度条实时显示执行轮次与清单进度，清单未了结自动催办
  • 输出截断四层防线：6 轮断点续写 + 截断守卫 + file_append 分段补齐，超长文件一定写完整

🛡️ 永不卡死的四层防线

长任务最怕转圈转到天荒地老。SLATE 布下四道防线，从连接层一路兜底到界面——任何一层出问题，后面的层都会接住。

就像电路里的断路器，跳闸会自动保护，还能一键复位——不会让你对着死界面干等。
  • 流式 idle 看门狗：90 秒无数据主动断开
  • 零内容自动退避重试
  • 请求 / MCP 工具 180 秒超时
  • UI 兜底看门狗强制恢复界面
// frontend/js/services/api.js
STREAM_IDLE_TIMEOUT_MS = 90000
STREAM_MAX_RETRIES     = 2
REQUEST_TIMEOUT_MS     = 180000
// 慢 ≠ 死：持续有数据永不干扰

装完 SLATE，你能得到什么

把读书笔记、会议纪要、资料片段交给知识库沉淀，想用时一句话召回。长期记忆跨会话生效，越用越懂你的表达习惯。

写作与文案搭子

从提纲到成稿多轮打磨；AI 团队辩论帮你挑出最有说服力的版本；提示词工厂让成稿风格稳定可复现。

轻量开发助手

读代码、改文件、跑命令、生成文档、PPT 与图表，这些都由 21 个内置工具在沙箱里完成；不想让它动手，也能只出一份高质量 Prompt 交给专业 Coding Agent。

想法推演板

新项目、新方案先在白板上摊开：卡片列需求、箭头连依赖、Mermaid 出流程图，把模糊的灵感推演成可执行的路径。

⏳

自动化小秘书

每天早上自动汇总资讯、每周定时整理文件、定点执行例行检查——定时任务到点就跑，结果自动归档，无需人工值守。

Tech Stack

原生技术，零构建

前端即文件，改完即生效；没有 npm，没有打包器，没有框架税。对开发者来说，它是一份可以逐行读完的源码；对普通用户来说，这意味着更少的依赖、更快的启动、更少的出错环节。

顺带解释一个常见词：Token 是 AI 计费与记忆的"字数单位"——上下文越长越费钱，也越容易忘。SLATE 的智能上下文压缩会把旧对话浓缩成摘要，相当于给聊天记录做"笔记归档"，省 token 又不丢要点。

层级选型这意味着什么
前端原生 HTML + CSS + JavaScript（ES Modules，零构建）打开文件就能改，改完刷新即生效
后端Python 3.13+ · FastAPI · Uvicorn · httpx轻量服务，一条命令启动
存储SQLite（对话历史）· JSON（状态 / 定时任务 / 宪法）无外部数据库，数据全在你硬盘上
渲染Highlight.js · Mermaid.js（CDN）代码高亮与流程图开箱即用
桌面webview2 壳 + PyInstaller 打包 + Inno Setup 安装器Windows 双击安装，像普通软件一样用

纯黑白灰基底

无蓝紫渐变、无夸张圆角、无阴影毛玻璃。金色只做点缀——像砚台上的一抹金漆，安静而有分量。

本地优先

数据全部存本地，API Key 仅用于 LLM 调用。你的对话、记忆、文件不经过任何第三方服务器中转。

Token 节约

智能压缩、分级调用、静默处理。让每一个字都花在刀刃上——少花钱，多办事。

永不卡死

四层超时防线，流式与工具调用全程兜底。慢可以等，但绝不允许无限转圈。

Quick Start

三步开始研磨

不写代码的朋友只看第一步：下载安装包，双击安装，和日常软件一样打开就用。想读源码或二次开发的伙伴，三步都看一遍。

01

获取 SLATE

前往 Releases 下载 Windows 安装包开箱即用；或克隆源码自行探索：

git clone https://github.com/CaryWang1234/SLATE.git
02

启动

源码运行需要 Python 3.13+，两条命令即可启动本地服务：

pip install -r requirements.txt
start.bat  # 或 ./start.sh
03

配置模型

在设置中填入所需模型的 API Key（各家模型官网申请，按量计费，日常用量成本极低），然后访问：

http://127.0.0.1:8000

安装后你会得到：一个带双主题的三栏工作台、全部内置工具、定时任务调度器，以及一份全部存在本地、随时可查的使用数据。卸载干净，不留残余。
