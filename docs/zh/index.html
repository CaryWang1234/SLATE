差异点

四件托管 Agent 很难做到的事

这不是比谁的功能多。下面四条都由同一件事推导出来——运行时归谁。每条也都能在本仓库里核对，所以请把它当代码评审，别当宣传文案。

01

你的密钥不经过我们——因为没有「我们」。

砚不持有主密钥，也不经任何厂商云中转。各厂商密钥你在本机粘贴一次，之后它随每次请求从你的电脑直达你选定的端点。

常见托管型 Agent

用量按厂商设定的积分计量，额度是他们给的。你的提示词、代码、文件被索引到他们的服务器上；这个月能试哪个模型，取决于他们开放了哪个。

砚

自带密钥、自带算力。四种协议之间随手切换——草稿用便宜的，定稿用强的；或者接一个从不出房间的本模型。没有锁定，换供应商也不用交切换费。

# backend/routers/proxy.py
_stream_openai / _stream_responses
_stream_anthropic / _stream_google
# 密钥随请求一起进来，服务端不留档
# 无账号、无登录、无订阅

证据： backend/routers/proxy.py backend/routers/settings.py frontend/js/store.js

02

每一步，都是事后可读的一行记录。

整套系统只有一套循环内核，它按顺序发出事件：每一次规划、开始、完成、取消都落进本地账本。屏幕上看到的不是滚动的日志，而是这份记录投出来的影。

常见托管型 Agent

一个转圈的进度条，加最后一段 diff。第 14 轮跑歪了，把局面扭成那样的推理和半途调用，你已经取不回来。

砚

带序号校验的事件落盘，重试也不会把一次调用记成两次；每条事件带摘要。同一条记录同时喂工具卡片、白板步骤卡和会话总结——一份真相，三个视图。

-- data/chat_history.db
runs        (run_id, …)
tool_events (run_id, seq, kind, …)
  UNIQUE(run_id, seq)  -- INSERT OR IGNORE
call.start → call.finish | call.cancel
单条摘要上限 2000 字符

证据： frontend/js/services/agent_loop.js frontend/js/services/agent_ledger.js backend/routers/events.py

03

停止就是停止，空转会自己发现。

点停止会同时掐断模型流和工具流；对支持流式的工具，后端把「流被关掉」直接当作取消信号，并终止正在跑的子进程。外面再套四层，保证「慢」不会变成「卡死」。

常见托管型 Agent

「停止」只停界面，任务还在别处继续跑、继续烧 token。循环卡在同一个失败调用上空转，得靠人盯出来。

砚

90 秒无数据即断流、空返回自动退避重试、请求与工具 180 秒超时、界面兜底看门狗。重复调用直接去重：连续 2 轮警告、4 轮止损并给出原因。参数没写完只做预览，绝不进执行。

// frontend/js/services/api.js
STREAM_IDLE_TIMEOUT_MS = 90000
STREAM_MAX_RETRIES     = 2
REQUEST_TIMEOUT_MS     = 180000
// chat.js — 空转止损
WARN_ROUNDS = 2 · EXIT_ROUNDS = 4
// skills.py — 关流即取消

证据： backend/routers/skills.py frontend/js/services/inkstream.js frontend/js/components/chat.js

04

加一项能力是丢一个文件，不是等一次发版。

34 个工具开箱即用。再往上，往本地技能目录扔一个 SKILL.md，下一条消息它就生效——@ 一下，上下文自己注入。

常见托管型 Agent

能力集就是厂商上个版本发的那些。想扩展，要么等别人的 roadmap，要么赌那套插件接口不被废弃。

砚

技能目录即插即用；MCP 客户端能接外部工具服务；砚自己也开着一个 MCP server，让别的 Agent 反过来调用它；其他 Agent 生态的技能目录可以原样导入。

# data/skills/my-skill/SKILL.md
---
name: my-skill
description: 这条技能教会砚什么
---
# 外接工具会以这样的名字出现：
mcp__{serverId}__{toolName}

证据： backend/routers/skills.py backend/mcp_client.py backend/routers/mcp.py backend/skills/plugin_adapter.py

能力半径

这四条差异，落到日常是这五件事

功能清单很长，这里故意不放。下面五个，才是「本地 + 可审计 + 自带密钥」换来的实际半径。

📦

交付物不止文字

一轮任务结束在能发出去的文件上：.pptx、.docx、.xlsx、PDF 正文与表格提取、SVG 图表、二维码、单文件网页包。改文件时 UTF-8 / BOM / GB18030 都保住，中文和 emoji 不会被写坏。

🧠

记忆留在自己盘上

聊天历史进本地 SQLite，本地向量知识库，Obsidian 式笔记库带 [[双链]]，长期记忆跨会话自动沉淀。没有一份内容被上传去「优化体验」。

📡

离开工位也管得到

开启局域网后，手机浏览器直接拿到一套专用移动版界面——同样的对话与工具循环，高危命令用底部抽屉确认。外加浏览器与桌面自动化，以及定时任务和事件驱动任务（文件变更 / git push / webhook）。

👥

不止一个脑子

几个模型先把方案辩一遍：提案、支持、反对、反驳、定夺，轻模型负责讨论、重模型负责拍板。DAG 流水线跑需求 → 拆解 → 编码 → 评审 → 归档，任务能拆时并行子代理同时开工。

🔍

源码可读，也不用构建

原生 ES Module，零 npm、零打包，改完文件刷新即生效。整个前端就是交付物，这一页的每句话都能落到一个具体路径上。

诚实边界

同样的自主，也要你付出同样的代价

只列优点的对比页就是宣传册。本地、单人、自带密钥是一笔交换——下面这几样，砚确实给不出。

没有托管工作区

无组织、无共享评审、无服务端 API。它是一个人桌上的工具，加团队协作会改变它的形态。

是护栏，不是监狱

terminal 跑的是真 shell。23 类高危命令先弹窗问你、灾难性命令直接拦死，但黑名单是栏杆，不是隔离舱。

密钥就在本地文件里

明文 JSON 躺在数据目录里，还没接系统钥匙串。能读那个目录的程序，就能读到它们。

不算离线运行

启动会加载 3 个 CDN 脚本（highlight.js、Mermaid、anime.js）。内网隔离环境得先把它们镜像到本地。

优先 Windows 与 macOS

Windows 安装包（需 WebView2）与 macOS 镜像有发布，Linux 只能从源码运行，没有打包产物。

局域网开的是整个应用

一旦开启遥控，那个网络上的设备就能驱动包括 terminal 在内的全部功能，只靠一个 token 和可选密码守。默认不开。

三步，然后自己判断

第一步就够不写代码的人用。第二、三步留给打算先读懂循环再信任它的人。

01

安装或克隆

Releases 里的 Windows 用户级安装包，不要管理员权限，卸载不留残渣。想读源码：

git clone https://github.com/CaryWang1234/SLATE.git
02

启动

从源码运行需要 Python 3.13+，两条命令拉起本地服务：

pip install -r requirements.txt
start.bat  # 或 ./start.sh
03

粘贴一个密钥

填任意一个你已有的模型密钥；或者指向本地的 Ollama / LM Studio，一个密钥都不用填。然后打开：

http://127.0.0.1:8000

没有要注册的东西，也没有要迁移的东西。第一次运行起，你的历史、记忆、技能和用量数据就只是本机磁盘上的文件。

拿它跟你已经在付费的那个 Agent 比一次。
